¿Cuáles son las tres formas de incluir CSS en un documento HTML?

Se puede incluir mediante una hoja de estilos externa (<link>), en la sección <style> del HTML (interno), o directamente en la etiqueta con el atributo style (en línea).


¿Para qué sirve el archivo styles.css externo en un proyecto web?

Sirve para separar el diseño del contenido, permitiendo controlar el aspecto de todo el sitio web desde un único lugar y facilitando su mantenimiento.


¿Qué propiedad de CSS se utiliza para cambiar el tipo de letra (fuente) de un texto?

Se utiliza la propiedad font-family, donde se especifica el nombre de la fuente o una lista de fuentes alternativas por si la principal no está disponible.
